# 01 · 创意

## 品牌与产品

**农夫山泉 · 长白雪**（天然雪山矿泉水，2021 上市；同系列另有「长白山天然矿泉水」2024 上市）。

产品事实（官方页面原文，见 03-SOURCES）：

- 源自长白山原始森林、距天池 < 60 公里的**自涌冷泉**
- 经**约 30–60 年**火山玄武岩深层溶滤、自然净化
- 恒温**约 7℃**
- 低钠偏硅酸型

## 洞察

这个品牌八年来最好的广告，都是**在山外面**拍的：雪、鹿、森林、四季、雾。
那不是错——那是它的证据链。但证据链里缺了一环：**那三十年到底长什么样**。

消费者听过「三十年」这个数字，但没有人见过它。数字在文案里，时间在石头里。

## 主张（single-minded proposition）

> **你喝到的，是三十年前的雪。**

一句话把「水源地」翻译成「时间」。不需要「纯净」「天然」「矿泉」这些词——它们都在这一句里。

## 为什么必须是 AI 才能拍

那三十年发生在玄武岩裂隙里，**任何摄影机都进不去**：没有光、没有空间、没有第二个机位。
传统做法只能拍岩石表面 + 水下摄影棚 + CG 重建；CG 重建要建模、要打光、要渲染农场，一个独立创作者做不起。

生成式模型把这件事变成可能：**同一次连续下坠**，从雪花到瓶身，中间那三十年是"生成"出来的，不是"搭建"出来的。
这不是"用 AI 省钱"，是"用 AI 去一个摄影机去不了的地方"——正是这个类别要的 *beyond traditional production constraints*。

## 片子怎么讲

30 秒，8 个镜头，一次向下的运动：

```
雪（外面） → 落在石头上 → 进裂缝 → 岩层里（三十年） → 更深处 → 涌出（7℃） → 瓶（雪线上） → 字
```

镜头语言只有两种：**极缓的推 / 极缓的拉**。没有摇、没有手持、没有花哨转场。
唯一"炫"的地方是 S4 的下坠——那是全片的重心，也是"不可能拍到"的那一镜。

光的节奏承担"时间"：从 S3 开始，每一层岩石的亮度比上一层低一点；到 S5 几乎全黑；
S6 涌出时第一次出现"水面反光"。观众不需要看字幕也知道"过了很久"。

## 三个不做的决定

1. **不加音乐**。加音乐会把这 30 秒变成"情绪片"；只有风、石、水和一个低音钟，才像一段真的等待。
2. **不出现人**。人一出现，观众就会去看人脸，而不是看时间；而且这是我们在别的片子里踩过的坑（脸与手最容易失真）。
3. **不喊卖点**。不说"低钠""偏硅酸"——30 秒只装得下一个词：**时间**。
