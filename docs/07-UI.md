# 07 · 视觉规格与尺子

## 1. 风格预设

| 项 | 设定 |
| --- | --- |
| 媒介 | 30 秒 TVC，16:9，1920×1080，24fps |
| 光学 | 长焦压缩（S1）、100mm 微距（S2–S6）、85mm（S7）；浅景深 |
| 色温 | 全片冷：B 通道 +5.5%，R 通道 −3.5%；黑位抬 0.9–1.4%，避免死黑 |
| 对比 | 低反差、高光不过曝（无明显纯白块，除末屏文字） |
| 质感 | 35mm 颗粒 0.75%，暗角 28%，gate weave 不加（数字稳定更"广告"） |
| 运动 | 只有极缓推/拉（z 1.00→1.20 上限），无摇、无手持、无旋转 |
| 声音 | 只有风、石、水、一个 110Hz 低音钟；**无音乐、无旁白** |
| 字体 | 中文思源宋（正文 34px / 末屏 46px / 字标 62px Heavy）；英文 Segoe UI Light，字距 0.24em |
| 禁忌 | 暖色、镜头光晕、快速剪辑、人物、产品旋转、任何"科技感"图形 |

## 2. 尺子（5 件，各学一点）

| # | 作品 | 学哪一点 | 不学哪一点 |
| --- | --- | --- | --- |
| R1 | 农夫山泉《长白山四季》水源地纪录片 TVC（品牌自 2018 年起持续拍摄） | 产品最后 3 秒才出现；全片只有自然声，没有一句旁白 | 不学它的"航拍大全景"——我们没有真实航拍素材，AI 生成的远景最容易露怯 |
| R2 | 农夫山泉 长白雪 水源地 TVC（雪花→渗入玄武岩→30–60 年溶滤→7℃ 自涌冷泉） | 把"年份"讲成一个物理过程，而不是文案里的数字 | 不学它的"实拍纪录片"姿态——我们要去的正是摄影机进不去的地方，姿态必须不同 |
| R3 | Guinness《Surfer》（1999，Jonathan Glazer） | 敢等：一整支片子只为一次"终于发生"；一句格言收尾 | 不学它的黑白高反差与大批群演 |
| R4 | Volvo Trucks《The Epic Split》（2013） | 一个**不可能的动作**，一镜到底，产品是支点 | 不学它的"明星 + 特技"——我们的不可能发生在石头里 |
| R5 | Sony Bravia《Balls》（2005） | 一个视觉做到极致就够了：25 万个球从旧金山街头滚下 | 不学它的高饱和彩色——我们全片只有一个色系 |

**过线标准（闸 D）**：成品与这 5 件混在一起随机命名，交给至少两位未参与的评委排名；每一位都把它排在至少 3 件尺子之上才算过。

## 3. 一个记忆点

> **光是一年一年暗下去的。**

S3 进水、S4 下坠、S5 几乎全黑：三层岩石，三层亮度，观众在没有任何字幕提示的情况下感到"过了很久"。
这是全片唯一"设计过"的东西；其余全部让位给它。

## 5. UI 量测（构建时自动跑）

- 所有文字包围盒距画面边缘 ≥ 5%
- 字幕包围盒不与画面主体（人/产品）相交：本片无人物；S7 的瓶子包围盒由 `scripts/measure_ui.py` 检测并与字幕区求交
- 末屏各行不重叠（相邻行基线差 ≥ 字号 × 1.15）
- 字号最小值 ≥ 13px（1080p 下约等于 0.7% 画高）
